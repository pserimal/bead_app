## Destination

完成一次性架构重写：Spring Boot + Kotlin 成为唯一对外 API、业务和数据库服务；Python 仅作为内部 CRNN 图像处理服务；React 前端继续可用；旧 FastAPI backend 最终退役，同时保留训练数据、标注数据和训练好的模型能力。

## Notes

- Domain: 拼豆图纸（Blueprint）、单元格（Cell）、识别任务（RecognitionJob）、颜色库（ColorLibrary）。
- This is a planning map: resolve decisions before implementation; do not use it as an implementation task list.
- Consult `domain-modeling`, `codebase-design`, `research`, `tdd`, and `frontend-design` when a ticket calls for them.
- One-time rewrite; no old API compatibility layer and no old business-data migration.
- Local Markdown tracker is being used because GitHub CLI/remote are unavailable in this environment.

## Decisions so far

- [一次性重写与旧 FastAPI 退役边界](issues/001-big-bang-rewrite-and-fastapi-retirement.md) — 采用一次性重写，旧 FastAPI runtime 最终删除，不保留兼容层。
- [Python CRNN 内部服务与训练资产边界](issues/002-python-crnn-service-and-training-assets.md) — Python 作为内部 FastAPI CRNN 服务，训练数据、标注和 checkpoint 保留为离线资产。
- [用户裁剪识别与编码输入规则](issues/003-user-crop-and-code-input-rules.md) — 只保留用户裁剪路径，裁剪参数必填，编码规则固定并统一大写。
- [RecognitionJob 异步进度与追踪生命周期](issues/004-recognition-job-progress-and-trace.md) — 任务与 Blueprint 分离，逐 Cell 回调进度，支持重试、心跳和追踪。
- [数据、颜色库快照与部署边界](issues/005-data-color-snapshot-and-deployment.md) — Spring Boot 独占数据库和文件，颜色库/模型使用快照，首版采用 Docker Compose。
- [React 前端与新版 REST API 范围](issues/006-frontend-and-api-scope.md) — 保留 React，改为单裁剪上传和 `/api/v1` 资源导向 API。
- [Spring Boot `/api/v1` 对外 DTO 与错误契约](issues/007-spring-v1-api-contract.md) — 完整契约：jobs/blueprints/colors 资源树、multipart 创建、JobDetail、事件流子资源、分页信封、结构化错误码。
- [RecognitionJob 持久化、事件日志与恢复事务](issues/008-recognition-job-persistence.md) — 5 表 Flyway schema；`(job_id,attempt,sequence)` 幂等键；终态事务内原子创建 Blueprint；90s stale 心跳扫描 + 最多 2 次重试。
- [Python CRNN 内部任务与逐 Cell 事件契约](issues/009-python-internal-event-contract.md) — multipart 任务请求 → 202；单一回调 `POST /internal/jobs/{id}/events`；序列号发送前分配、重传复用；1s..16s 退避；颜色映射唯一权威在 Spring。
- [CRNN 训练推理共享核心与模型 artifact 边界](issues/010-crnn-runtime-artifact-boundary.md) — 新建顶层 `ocr_core/` 包；checkpoint 加元数据+硬校验（修复 37-vs-14 崩溃）；`publish_checkpoint.py` 不可变 artifact + 只读挂载；R4 sever list。
- [迁移前 CRNN 用户裁剪基线与验收方法](issues/011-crnn-migration-baseline.md) — 实测基线：`crnn_real_m.pt` zip 集 exact_match 0.7008、0.975 ms/cell；验收 ≥0.7008±0.005；发现阻断级置信度 bug（F1）。
- [单裁剪上传、任务历史与只读追踪交互](issues/012-frontend-job-trace-flow.md) — “Pegboard”原型（30/30 校验通过）；处理中不展示半成品棋盘、追踪视图替代；UNMAPPED 三处同词汇；固定 2s 轮询。
- [Docker Compose 服务拓扑、健康检查与恢复](issues/013-compose-runtime-recovery.md) — 3 服务 1 对外端口；pg_isready/actuator/model_ready 健康检查；单向依赖闸门；unless-stopped；反模式移除。
- [旧 FastAPI backend 退役与训练资产迁移清单](issues/014-legacy-backend-retirement-checklist.md) — 阶段 0-4 可执行清单：快照→迁移→依赖清理→删除→回归验证；5 项需用户确认。
